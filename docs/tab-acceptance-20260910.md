# MinaSCP 0.4 分頁與連線資訊驗收

日期：2026-09-10；macOS 26.7 arm64，最低支援 macOS 14。只使用本機 SFTP fixture 與 loopback Docker 22222／22224，未連正式主機。

## 完成範圍

- 共用分頁命令層：非目前分頁右鍵、連線生命週期、別名／色彩與恢復預設、獨立複本、另存站台草稿、分组站台選單、已開啟分頁清單、關閉／關閉其他／關閉右側與快捷鍵。
- SwiftUI 原生 DragGesture 依分頁畫面位置排序；只接受分頁內的手勢，不接收外部檔案。左右半部決定插入位置，保存順序與目前分頁。
- 命令／封存驗證與屬性寫入阻擋分頁離開；批次操作先整批檢查，獨立背景工作提示後繼續。舊 workspace 缺少新欄位仍可載入。
- 兩頁資訊綁定實際瀏覽連線及連線世代。SSH 診斷白名單、有界解析、跳板不確定資訊標未知；SFTP 握手擴充排序顯示。資訊不含原始診斷、密碼或私鑰內容。
- 未加入可用空間、工作階段 URL／程式碼、命名工作區、隱藏標籤列；既有跨站台本機容量檢查保留。

## 實際 App 驗收

- 目前停在 SSH 分頁時，右鍵第一個 SFTP 分頁執行命名、紅色色彩、重複及連線；目前分頁標記與來源操作正確，側欄保存站台名稱未變。
- 重複分頁插於來源右側，未連線來源保持未連線，雙欄路徑相同；名稱、色彩重啟後保存。結束驗收已關閉測試複本，恢復來源分頁預設名稱／色彩。
- 實際向左與跨頁向右拖曳，畫面順序正確；正常退出後重啟仍保留順序，沒有自動連線／工作。
- ⇧⌘D 複製、⇧⌘W 關閉後選右鄰、⌘T 打開站台管理；關閉右側只移除右側測試複本。另存帶入目前端點及雙欄路徑，取消後站台檔與驗收前逐位元組相同。
- SFTP-only 22222 協定頁顯示 OpenSSH_10.0、SFTP-3、雙向 aes128-gcm@openssh.com、compression none、ssh-ed25519 與實際 SHA-256 指紋；唯讀命令探測回報不可用。
- SSH 22224 顯示不同目的主機指紋，唯讀探測回報 python3、tar、touch、unzip、zip。兩頁截圖保存在 `evidence/tabs-ssh-protocol.png`、`evidence/tabs-ssh-capabilities.png`。
- 資訊視窗開啟期間透過主選單切換分頁，快照不變；中斷來源連線後顯示「已中斷／上次連線資訊」，能力探測按鈕停用，原資料保留。證據：`evidence/tabs-disconnected-info.png`。
- 點擊複製資訊後實際讀回系統剪貼簿，確認包含兩頁與排序擴充，不含 debug1、AskPass、密碼欄位或私鑰內容。
- 新增本機分頁曾卡在 Foundation `getxattr`；執行緒採樣確認後，清單改只用 lstat 取得 POSIX 資訊，不追隨符號連結。修正後同一個家目錄能正常顯示，本機分頁可關閉且 App 可正常退出。此修正避免已觀察到的延伸屬性卡點，並非宣稱所有網路磁碟存取永不阻塞。

批次關閉阻擋、進行中的屬性／命令／傳輸護欄由實際程序與檔案操作的自動測試驗證；未將它們寫成全部逐一手動 UI 驗收。
