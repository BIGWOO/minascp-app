## 尚未完成的人工驗收

以下未宣稱通過。這次滑鼠座標自動化沒有可靠觸發拖曳；原生 provider 回呼測試不能取代實際 Finder 操作。

1. Finder `.local-sftp/finder-upload` 同時選取文字檔與資料夾，拖入右欄測試子目錄，確認佇列及子檔內容。
2. 右欄同時選取多檔與資料夾，拖到 Finder 的新空目錄，確認檔案完成、失敗提示與取消。
3. 拖曳開始後切換分頁，確認來源仍固定在原站台；拖至子目錄列，確認目的地正確。
4. 確認實際鍵盤 Tab 切換焦點與欄位拖曳保存手感符合日常習慣。

互動驗證碼、多跳 ProxyJump、外部網路斷線與非 OpenSSH 伺服器沒有實機覆蓋；程式遵循 OpenSSH 行為，但不能將相容性設計視為已實测。SHA-256 前檢查並不是跨客戶端鎖定，最後檢查與覆蓋之間仍有協定限制。
