# 右鍵選單對齊 WinSCP：2026-09-10 驗收

## 已交付

四種情境選單（檔案、資料夾、多選、空白處），分隔線／圖示／快捷鍵，面板與來源快照，共用可用性驗證。背景選單保留選取、操作目前目錄。導航／書籤／篩選／名稱路徑複製、新增檔案／資料夾／符號連結已接入。

上下載可指定目的資料夾；同端複本及移動支援單項完整路徑與多選目的資料夾，進入持久化佇列，提供取消／重試與逐項結果。同端衝突只有略過或自動改名，不提供覆蓋。同端移動採不覆蓋 rename；遠端複製串流經 Mac，不依賴遠端 shell。

⌘C／⌘V 支援本機、同一站台遠端及跨本機／遠端貼上，Finder 檔案 URL 可貼入。遠端剪貼簿包含站台 UUID、端點摘要與來源路徑，不含秘密；站台、連線端點或連線狀態不符時停用。文字欄位沿用文字複製貼上。

屬性視窗整合資訊、RWX／八進位、UID／GID、混合值、可選遞迴；只修改明確編輯欄位。套用前讀取全部作用範圍與原值，子項目優先寫入、逐項讀回；還原父目錄優先，支援顯示部分失敗。缺少原值不寫入，跳過符號連結。操作中阻止關閉視窗與結束 App。

## 邊界與回復

- 跨站台複製、壓縮解壓、自訂指令，以及遠端剪貼簿貼至 Finder 不在本批；遠端拖至 Finder 沿用既有 file promise。
- 批次非交易：取消或部分失敗保留已完成項目。目錄複本取消可能留下已建目錄與完成檔案；佇列保留暫存和續傳資訊。
- 屬性原值保留在當次視窗記憶體；關閉後無跨重啟還原。伺服器不允許的 UID/GID 修改仍會失敗，不提升權限。
- OpenSSH 優先使用 lsetstat；沒有該擴充的 SFTP 伺服器採種類檢查後 SETSTAT，不能保證對抗其他程序在兩步之間替換路徑。
- App 為本機 ad-hoc 簽章，未公證或發布。舊版 App 保存在 `build/backups/context-menu-before/MinaSCP.app`。新版加入遠端複製佇列種類；舊版無法解碼這類紀錄時會禁止覆寫。若需回復舊版，先另存目前 transfers.json，不能直接覆蓋或刪除現有佇列／編輯副本。

最終版重啟後再次以 ⌘I 開啟屬性，套用 0640 後還原，欄位立即回到 0600、群組 R 回到未勾選，讀回訊息一致。移動紀錄顯示「遠端移動」，完成進度為 100%，不再顯示傳輸 0 bytes。新版已重新連線 Docker 並保留主視窗，24 筆既有驗收佇列均完成。
