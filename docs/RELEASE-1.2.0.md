# MinaSCP 1.2.0

## 修正
- 從本機上傳並覆蓋遠端既有一般檔案時，保留遠端原本的擁有者、群組與完整 Unix 權限，不再被暫存檔的 0600 權限取代。
- 在原子替換前還原屬性並讀回驗證；帳號權限不足、屬性缺失或傳輸期間目的檔案屬性改變時，停止覆蓋並保留原檔及暫存檔。
- 這項保護也適用於使用同一上傳流程的遠端編輯存回。已被舊版改動的屬性無法自動推回原值，需依伺服器原設定還原。

## 新增
- 雙擊本機或遠端路徑列，開啟「位置設定組合」視窗；也能透過路徑列按鈕或面板選單開啟。
- 可輸入本機／遠端完整路徑、選擇最近路徑或瀏覽本機資料夾，再切換兩側目錄。
- 支援站台專用與共用位置組合，提供新增、重新命名、移除、上下排序，並保存供下次使用。
- 原有路徑麵包屑、書籤及 ⌘L 編輯完整路徑維持可用。

## 開發建置
- 建置成功後替換舊 App，不再累積 MinaSCP-previous-*.app；替換失敗時還原原 App。

## 相容性與安裝
- 需要 macOS 14 或更新，支援 Apple Silicon 與 Intel。
- 1.1.0 使用者可從「MinaSCP → 檢查更新…」下載安裝；1.0.0 使用者需手動安裝一次。
- 沿用正式 Sparkle Ed25519 金鑰與手動更新流程；App 維持 ad-hoc 簽章，尚未經 Apple Developer ID 簽署及公證。

## 本輪驗證
- 含本機 Docker SFTP／SSH 的回歸測試通過；壓力測試與需另外啟用的中斷測試不計為通過。
- 實際操作確認雙擊路徑列可開啟位置視窗，共用組合可新增、讀回與移除。
- Universal 發版產物及 Sparkle 更新清單、ZIP、更新說明均於發布前驗證簽章。
- 未在其他實體電腦重跑安裝與 Intel／macOS 14 驗收。
