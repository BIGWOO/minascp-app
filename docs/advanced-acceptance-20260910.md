## 已交付

- `CrossSiteManager` 與獨立版本化工作檔，保存固定端點、來源基準、暫存與子工作；全部下載校驗後才上傳，完成獨立雜湊／連結讀回才清理。暫停、取消、重啟保留，手動恢復重驗來源及暫存；子工作完成紀錄在父工作結束前不能被「清除完成」移除，也不能從一般佇列直接重試繞過父工作驗證。
- 「製作複本…」預設目前站台，可改選其他保存站台；跨站台掃描顯示內容大小與空間需求，同名只略過／改名。目錄準備後才出現的同名資料夾拒絕合併。
- `RemoteCommandRunner` 使用獨立 SSH 程序，沿用主機信任、AskPass、私鑰、ProxyJump。stdout／stderr 各最多 2 MiB；逾時／取消或 SSH 狀態不明不自動重試。
- 檔案／目錄自訂指令選單、能力探測與本次連線快取、永不略過的命令預覽、工作紀錄與輸出。斷線後舊情境立即停用；首次探測完成直接更新選單。
- ZIP、tar.gz 先產生唯一暫存並驗證可讀，再不覆蓋改名；解壓縮受控 Python 腳本先驗證所有成員再寫入，拒絕穿越、重複、連結及特殊檔案。
- 偏好設定集中管理範本、四種情境、整批／逐項、逾時與四個參數變數。未知變數或不安全的引號位置會阻止展開。

## 明確限制

- 自訂命令可以有不可逆效果；停止本機 SSH 不代表遠端程序已停止。失敗遠端暫存提供完整路徑，不自動清理不確定仍被使用的內容。
- 解壓縮不支援加密 ZIP、連結與特殊成員；最多 100,000 成員、100 GiB 展開量，須有 Python 3。
- 遠端來源掃描與目的獨立驗證都會讀取完整檔案；這不是伺服器快照，不能鎖住其他客戶端的同時修改。SFTP 的路徑操作也不能提供跨請求的完整交易隔離。
- 跨站台首版不覆蓋或合併目的資料夾；來源／端點／完整暫存不一致時須重新建立工作。清理本機暫存後不能恢復。
- 未實測正式主機、所有不同發行版工具版本、互動命令或大型封存的效能；只以兩個本機 OpenSSH 容器驗收。
