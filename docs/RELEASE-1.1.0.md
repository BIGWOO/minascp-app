# MinaSCP 1.1.0

## 新增
- 「MinaSCP → 檢查更新…」：顯示新版資訊與更新內容，由使用者決定是否下載與安裝。
- 下載更新後可安裝並重新啟動；工作忙碌時延後，完成後需再次確認。

## 改善
- 更新套件與更新清單使用 Sparkle Ed25519 簽章驗證。
- 保留工作區、偏好設定與站台資料。

## 修正
- 本版無獨立錯誤修正項目。

## 相容性與安裝
- 需要 macOS 14 或更新，支援 Apple Silicon 與 Intel。
- 1.0.0 使用者需要手動安裝本版一次，之後可在 App 內檢查更新。
- 本版沿用 ad-hoc 簽章，尚未經 Apple Developer ID 簽署及公證。
- 僅手動檢查，不會背景檢查、下載或安裝。
